My DevOps journey

A practical, step-by-step path — learning each tool by actually using it, then connecting the pieces into one automated workflow.

  1. 01

    Linux & development environment

    Got comfortable with the command line, file systems, and setting up a proper development environment as the foundation for everything that followed.

  2. 02

    Git & GitHub

    Learned version control fundamentals — branching, commits, and pull requests — and used GitHub as the source of truth that triggers the pipeline.

  3. 03

    Docker & containerization

    Practiced writing Dockerfiles, building images, and packaging an application so it runs consistently anywhere.

  4. 04

    AWS cloud

    Explored core AWS services and how they fit together to host and run a containerized application in the cloud.

  5. 05

    CI/CD automation

    Connected CodePipeline and CodeBuild so that a code push automatically builds and prepares a new container image, with no manual steps.

  6. 06

    ECS Fargate deployment

    Deployed the container to Amazon ECS on Fargate, running the application without provisioning or managing servers directly.

  7. 07

    Production-style deployment

    Brought every stage together into a single automated flow — from a Git push to a running container — structured the way a real deployment pipeline works.
