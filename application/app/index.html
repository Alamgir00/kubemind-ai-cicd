Featured project

KubeMind AI — Production-Style AWS CI/CD

A complete CI/CD platform provisioned with Terraform and designed to automate the path from GitHub source code to a running container on Amazon ECS Fargate.

01 / SOURCE

GitHub

GitHub remains the source repository and the starting point for the automated delivery workflow.

02 / BUILD

CodePipeline + CodeBuild

A code change triggers the pipeline, builds the application and creates the Docker image.

03 / RELEASE

ECR + CodeDeploy + ECS

The image is stored in ECR and deployed through CodeDeploy to ECS Fargate using a blue/green deployment model.
